Why

What changes when the agent has to show its work instead of narrating it.

Without

  • The plan is 200 lines of chat you scroll past
  • "Done!" after code nobody ran
  • You read a diff to learn what changed
  • An API call written from memory, for last year's version
  • Every session starts from zero

With suwagent

  • A plan page with a diagram, a file map and steps, approved with one button
  • Every answer ends with 🟢 done, 🟡 pending or 🔴 waiting for you
  • A recap: roles, a real scenario, before/after, the spec's criteria ✓ / ✗
  • The official docs of the installed version, read first and named
  • A session hook brings the same working agreement everywhere

One larger task, start to finish

The agent offers each page in one line. Small changes skip all of it.
